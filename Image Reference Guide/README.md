# Image Reference Guide

This folder contains a copy of every image currently used on the Ice Bath NZ website, organized by product and page location.

## Purpose

Use this as a visual reference to see exactly which images appear where on the site. When you want to replace a photo, simply follow the steps below.

---

## How to Replace an Image

1. Find the image you want to replace in this folder structure
2. Create your new image with the **same dimensions and format** (WebP preferred, 1:1 ratio for catalog cards, 3:2 ratio for hero images)
3. Name the new file: `original-filename-NEW.webp`
   - Example: replacing `hero-image.webp` → name the new file `hero-image-NEW.webp`
4. Place the new file in the **same folder** as the original
5. Let us know and we'll swap it into the live site

### Naming Convention

- `NEW` suffix tells us this is a replacement file ready to be swapped in
- Keep the same file extension (.webp, .avif, .png)
- Keep the same aspect ratio as the original

## Image Size Guidelines

| Image Type | Recommended Ratio | Notes |
|---|---|---|
| Hero images (desktop) | 3:2 landscape | Full-width background images |
| Hero images (mobile) | 2:3 portrait | Mobile-specific hero variants |
| Catalog cards | 1:1 square | No-background product shots preferred |
| Gallery/carousel slides | 1:1 square | Can be lifestyle or product shots |
| Social share (og:image) | 1.91:1 landscape | Used when sharing links on social media |
| Split screen backgrounds | 16:9 or wider | Lifestyle/environmental photos |

## Format

- **WebP** is preferred for all new images (best quality-to-size ratio)
- Keep file sizes under 200KB where possible
- Minimum resolution: 1200px on the longest edge
